# Areca Backup - Disclaimer Regarding the Release of Untested Platforms

The following bundles have not been run or tested,
so it is unknown whether they run like the other tested bundles (Windows/Linux and x86-64/32)
or if they fail or have platform-specific issues.
This is especially true for the operating system,
as a testing environment is not available.
Therefore, support for these bundles is very limited.

Platform support (operating system + microprocessor architecture),
depends on the availability of support for a specific version of the SWT library for that platform.

The original SWT version, 4.3, is very old,
and updating to the latest versions could involve changes to the source code due to breaking changes in its API.
Additional platforms may be supported as SWT is updated, but this, in turn,
could mean that other platforms lose support, especially older ones like x86-32.

**These untested bundles are provided in case they might be useful to someone,
but support for them is very limited**, at least until a testing environment is available.

Feedback regarding their functionality is welcome.
If positive feedback is received on a bundle's behaviour,
it will be placed in the top-level folder ("tested") in future releases.
